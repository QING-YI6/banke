半刻 · 四瓣番茄钟
==================

【电脑上直接用】
双击 半刻.html（或 启动半刻.cmd）。
不需要安装，不需要联网。记录会存在你打开它的那个浏览器里。

如果双击后是空白页，换 Chrome / Edge 打开试试。
想要一个独立窗口的 exe，按 README 里的 GitHub Actions 步骤生成。

【手机上安装】
1. 把这个文件夹推到 GitHub。
2. 打开仓库的 Actions → build-android → Run workflow。
3. 跑完后下载 Artifacts 里的 banke-android-debug。
4. 解压得到 app-debug.apk，传到手机安装。
   第一次安装要允许「安装未知来源应用」。
5. 图标叫「半刻」。这是 debug 版，适合自己和朋友用。

【怎么用】
- 开场等番茄被切成四瓣，拖动水面可以转视角。
- 点任意一瓣进入；可以写一句要做什么，也可以直接跳过。
- 计时器中间的数字点一下，可在倒计时 / 正计时之间切换。
- 切下来的「柄」在水面左下角，点它打开记录和设置。
- 设置里可以默认跳过输入、调时长、关声音、关灵宠、导出记录。

【数据】
没有账号，不上传。记录只在这台设备上。
重要记录建议在「柄 → 设置 → 导出 JSON」备份。

—— 为长时间坐着的人做的一颗番茄。
